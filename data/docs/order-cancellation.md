# 주문 취소 방법

## 취소 절차

1. [마이페이지] > [주문내역]에서 취소하려는 주문을 선택합니다.
2. 주문 상태가 "결제완료" 또는 "상품준비중"인 경우 [주문 취소] 버튼이 표시됩니다.
3. 취소 사유를 선택하면 즉시 취소 처리되며, 결제 금액은 결제 수단에 따라 환불됩니다.

## 취소 가능 여부

| 주문 상태 | 취소 가능 여부 |
| --- | --- |
| 결제완료 | 가능 (전체/부분 취소) |
| 상품준비중 | 가능 (판매자 확인 필요할 수 있음) |
| 배송중 | 불가능 (반품 절차 이용) |
| 배송완료 | 불가능 (반품 절차 이용) |

이미 발송이 시작된 상품은 주문 취소가 아닌 반품 신청을 통해 처리해야 합니다.

## 환불 소요 기간

- 신용카드: 카드사 승인 취소, 3~7영업일
- 무통장입금/계좌이체: 환불 계좌 등록 후 1~3영업일
- 적립금/쿠폰 사용분: 즉시 복원

## 자주 묻는 질문

- **일부 상품만 취소할 수 있나요?** 여러 상품을 함께 주문한 경우 상품별로 개별 취소가 가능합니다.
- **취소했는데 아직 환불이 안 됐어요.** 카드사 사정으로 실제 승인 취소까지 영업일 기준 최대 7일이 소요될 수 있습니다.
