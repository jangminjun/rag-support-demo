# 회원가입 방법

## 가입 절차

1. 홈페이지 우측 상단의 [회원가입] 버튼을 클릭합니다.
2. 이메일, 휴대폰번호 중 하나를 선택해 본인인증을 진행합니다.
3. 아이디, 비밀번호, 이름, 생년월일 등 필수 정보를 입력합니다.
4. 이용약관 및 개인정보 처리방침에 동의하면 가입이 완료됩니다.

## 소셜 간편가입

네이버, 카카오, 구글 계정으로도 별도의 정보 입력 없이 간편하게 가입할 수 있습니다. 소셜 계정 연동 시 이메일 정보만 자동으로 가져오며, 추가 정보는 마이페이지에서 직접 입력할 수 있습니다.

## 자주 묻는 질문

- **만 14세 미만도 가입할 수 있나요?** 만 14세 미만은 법정대리인 동의 절차가 필요하며, 별도의 인증 페이지에서 보호자 동의를 진행해야 합니다.
- **아이디를 잊어버렸어요.** 로그인 페이지의 [아이디 찾기]에서 가입 시 등록한 휴대폰번호 또는 이메일로 본인인증 후 아이디를 확인할 수 있습니다.
- **가입 축하 쿠폰은 언제 지급되나요?** 회원가입 완료 즉시 마이페이지 쿠폰함에 자동으로 지급됩니다.
