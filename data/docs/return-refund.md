# 반품/환불 절차

상품 수령일로부터 7일 이내에 반품 신청이 가능합니다. 단, 상품의 가치가 훼손된 경우(포장 개봉, 사용 흔적 등)에는 반품이 제한될 수 있습니다.

## 신청 절차

1. [마이페이지] > [주문내역]에서 반품하려는 상품을 선택하고 [반품 신청] 버튼을 클릭합니다.
2. 반품 사유(단순 변심, 상품 불량, 오배송 등)를 선택하고 상세 내용을 입력합니다.
3. 택배기사가 방문하여 상품을 회수하거나, 지정된 반품 접수처로 직접 발송합니다.
4. 상품 검수 완료 후 3영업일 이내에 환불이 진행됩니다.

## 환불 방법

- 신용카드 결제: 카드 승인 취소(영업일 기준 3~7일 소요)
- 실시간 계좌이체/무통장입금: 환불 계좌로 직접 입금(1~3영업일 소요)
- 적립금 결제: 적립금으로 즉시 환불

## 자주 묻는 질문

- **반품 신청 후 취소할 수 있나요?** 택배기사가 상품을 회수하기 전이라면 마이페이지에서 반품 신청을 취소할 수 있습니다.
- **일부 상품만 반품하고 싶어요.** 여러 개 주문한 경우 상품별로 개별 반품 신청이 가능합니다.
