# 쿠폰 사용 안내

## 쿠폰 확인 및 적용

발급받은 쿠폰은 [마이페이지] > [쿠폰함]에서 확인할 수 있으며, 주문서 작성 화면의 [쿠폰 적용] 항목에서 사용 가능한 쿠폰을 선택해 즉시 할인받을 수 있습니다.

## 쿠폰 종류

- **정률 할인 쿠폰**: 상품 금액의 일정 비율(예: 10%)을 할인
- **정액 할인 쿠폰**: 최소 주문 금액 이상 구매 시 정해진 금액(예: 5,000원)을 할인
- **무료배송 쿠폰**: 배송비를 면제

## 유의사항

- 쿠폰은 한 번의 주문에 1개만 적용 가능하며, 다른 쿠폰이나 적립금과 중복 적용될 수 있는지 여부는 쿠폰별로 다릅니다.
- 쿠폰 유효기간이 지나면 자동으로 소멸되며 기간 연장은 불가능합니다.
- 쿠폰을 사용한 주문을 취소/환불하면 사용한 쿠폰은 원칙적으로 복원되어 재사용할 수 있습니다.

## 자주 묻는 질문

- **쿠폰이 적용되지 않아요.** 최소 주문 금액 미달, 제외 상품 포함, 유효기간 만료 여부를 먼저 확인해 주세요.
- **친구 초대 쿠폰은 어떻게 받나요?** 마이페이지 > 이벤트 메뉴에서 초대 링크를 공유하면 친구가 가입 완료 시 양쪽 모두에게 쿠폰이 지급됩니다.
